# Phase 6 手动智能校验

## 操作

在编辑器点击“检查文档”。打开“质量检查”侧栏只查看状态，不启动分析。检查使用当前本地正文（包括未保存内容）与已生效文件设置，分析在独立 Web Worker 中执行。

报告显示问题级别、位置、依据、建议和命中证据，可筛选类别并定位到编辑器中的唯一节点。无法安全定位时明确说明原因。检查不修改正文、不保存、不产生新版本；光标和选区变化不会使结果失效。

正文、导入、版本恢复、远端更新或已生效设置变化后，报告标为过期、清除标记并停用定位。只有再次点击“重新检查”才会分析；切换文档清除上个文档的报告。中文组合输入期间提示先完成输入，不排队自动检查。

## 检查范围

| 项目 | 本期行为 |
|---|---|
| 结构 | 章条跳级、空章条/标题、同级有题/无题一致性、无题条再分条、孤立单条 |
| 悬置段 | 容器同时包含直接普通段落与直接子条时报问题；仅术语章及其内部容器豁免，属于项目约定 |
| 列项 | 仅识别引出语，不检查样式、层级与标点一致性 |
| 图、表 | 检查图表前引出语与相应正文提及；题注及对象自身内容不作为正文提及 |
| 附录 | 必须在正文提及；前置部分、自述及附录间互引不计 |
| 术语 | 正文至少出现2次；同段两次计两次，跨格式文本合并，结构化引用不重复计数 |
| 内部引用 | 结构化目标存在性、类型与定位完整性 |
| 规范性引用文件 | 本地有限格式规则：章节位置、标识语法、清单前序号及名称缺漏等 |

术语计数排除术语章、规范性引用文件章、前置部分、附录、标题、题注、注、示例、代码、公式来源及脚注。同名多项术语存在归属歧义时提示人工核对，仅计入可确认的结构化引用。

引出语和字面提及采用有限规则，报告中明确标为“有限覆盖”。识别常见编号、枚举和范围，并排除明确外部文件来源；不理解所有自然语言指代。零问题只表示本期启用规则未发现问题。

暂缓术语权威性、引用文件现行状态及编号/名称事实准确性；本期排除脚注、表脚注、参考文献提醒和图表格式检查。不提供一键改写或自动修复。

## 接口与兼容

共享入口为 `analyzeDocument(IRDoc)`，输出既有 Resolver 结果与独立质量报告。报告含稳定问题ID、证据、规则版本及各组覆盖状态；纯函数不读写主机或网络。

MCP `validate_document` 新增 `quality` 字段，保留既有 `revision`、`problems`、`exports`。旧 Resolver 问题和导出脚注保护继续按原接口返回，不能用新质量报告代替导出前检查。同一次读取的快照生成报告，不补ID、不写库、不产生版本或事件。
