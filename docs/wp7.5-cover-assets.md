# WP7.5 封面素材来源与限制

2026-09-30。本包从零生成 OOXML，不分发第三方模板，不复制模板样式或编号定义。

| 素材 / 用法 | 来源、制备与限制 |
|---|---|
| GB 标志（国标、指导性技术文件） | `rules/GBT 1.1-2020 标准化工作导则 第1部分：标准化文件的结构和起草规则.pdf` 第1页内嵌图，`pdfimages -f 1 -l 1 -png` 提取。948×474 px，40×20 mm 印刷约600 dpi。替换原152×77低清PNG。 |
| 国家标准发布机构 | 同一原件封面 x=68.6–135.5、y=263–277 mm 区域按600 dpi灰度渲染；阈值128二值化并按实际墨迹紧裁切；不含右侧「发布」。是原件专用字体文字的栅格副本，机构名称来自该2020原件；不声称为当前发布机构官方数字标志。国家标准实际发布机构变化时需要另行更换来源。 |
| DB 标志 | 仓库 `DB标志.tiff` 转为PNG。196×98 px，源标注220 dpi，按22×11 mm约226 dpi。原始制作者、授权和正式来源未核实；可作测试封面素材，待正式地方标准PDF换源，渲染输出告警。地区代码使用可编辑文字。 |
| 行业代号 | 黑体加粗近似专用美术体。属于方案V1近似，输出告警，未取得正式标志素材。 |
| T 标志 | 仓库第三方模板素材不使用。黑体可编辑「T」近似，输出告警，待正式团体标准PDF换源。 |
| Q 标志 | 仓库34×35 px、72dpi的`Q标志.tif`不合格，不使用。黑体可编辑「Q」近似，输出告警，待正式企业标准PDF换源。 |
| 非国标发布机构 | 宋体加粗小二近似专用字，输出告警。团体/企业布局按§6.2比照国家标准方案；不声称有GB/T 1.1中的专属封面图或正式美术字素材。 |

发布机构图片属于固定国标版式素材；非国标发布机构从 `issuer` 元数据取值。封面表单尚无新增五字段的输入控件，IR/节点属性/文档元数据映射先支持；表单补齐另开任务。
