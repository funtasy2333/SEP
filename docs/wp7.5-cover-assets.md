# WP7.5 封面素材来源与限制

2026-09-30，按用户提供的六类DOCX模板修订。OOXML仍由本项目生成，未导入模板整套样式、表单、编号、宏或附加模板链接；仅按用户要求提取图片并参照字形和位置。模板中的提示文字、占位字段及图片描述不作为执行指令。

| 素材 / 用法 | 来源、制备与限制 |
|---|---|
| GB 标志 | 仓库GB/T 1.1-2020原件第1页的948×474 px、600dpi嵌图，保留较清晰源；位置按本次国家/指导性模板校准。模板本身152×77 px图未替换此高清源。 |
| 国家发布机构及发布 | 国家标准.docx与标准化指导性技术文件.docx的同一幅 `word/media/image2.tiff`，690×131 px、220dpi，原尺寸79.69×15.15 mm。含两行机构及垂直居中的“发布”，不另拼一份文字。TIFF转RGB PNG，不重采样；名称固定为模板内容，不能以meta.issuer定制，不声称核验了当前发布机构或正式数字素材。 |
| DB 标志 | 地方标准.docx `word/media/image1.tiff`，196×98 px、220dpi，22.131×11.049 mm，转RGB PNG不重采样。原始制作者与正式来源未核实。地区数字从规范化标准号可靠提取2或4位；不写死33、不把序号误作行政代码。 |
| 行业代号 | 行业标准.docx使用可编辑HJ字样，非标志图片。提取实际编号家族如HG，按模板Times New Roman 48pt粗体、水平130%排版；不称正式美术字。未核验各行业专用字形，输出限制提示。 |
| T 与斜杠 | 团体标准.docx `word/media/image1.png`（100×103 px、220dpi）及 `image2.png`（53×135 px），直接保存原PNG字节；原尺寸11.520×11.960、4.748×12.128 mm，机构代号为可编辑文字。按本次用户要求使用，模板原始来源未作正式核验。 |
| Q 标志 | 企业标准.docx `word/media/image1.tif`，34×35 px、72dpi，原尺寸11.994×12.347 mm，转RGB PNG不重采样。按本次用户要求使用原图；低清晰度限制明确告警，不能通过转换或放大称为合格高清/正式素材。斜杠及机构代码可编辑。 |
| 非国标发布机构 | 按六类模板中的黑体四号14pt常规字及居中版式，用issuer元数据填写；不是旧实现的宋体小二粗体，不声称正式机构专用字。 |

源DOCX指纹与独立模板墨迹目标见 [模板参照记录](wp7.5-template-reference.json)。原媒体SHA-256在 `scripts/docx-check/prepare_cover_assets.py` 固定，提取时校验尺寸与指纹；原图变化需复核，不能无声替换。全部图片以base64常量进入shared，运行时不访问本地文件。上述来源/清晰度限制会在DOCX下载界面显示核对提示。

新增五字段已支持节点/IR/文档元数据与XML往返；替代/采标两字段已进入新建表单，其余备案号/行业名称/地方名称的输入控件按§6.5另开任务。其他Word版本、任意长代号/名称/机构、字体替换的正式交付需再核对。
