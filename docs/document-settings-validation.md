## 功能范围

编辑器顶部“文件设置”替换原占位页。沿用 SES 紫色主题，提供分组导航、实时信息摘要、表单卡片、底部保存与重置操作；支持桌面与窄屏布局。

| 分组 | 可修改字段 |
| --- | --- |
| 基础信息 | 标准类别、中英文名称、完整标准编号；行业、地方、团体、企业标准的标准类型名称片段 |
| 分类与阶段 | ICS、CCS、文档阶段 |
| 发布信息 | 发布日期、实施日期、代替标准、一致性程度标识、备案号 |
| 单位信息 | 提出单位、归口单位、发布单位、起草单位 |

文件设置覆盖新建文档中的全部信息，并补齐已有封面元数据的输入入口。新建和文件设置中，行业、地方、团体、企业标准在类别选择后显示统一的“标准类型”名称框；固定前后缀在框外显示，用户只填写中间名称。国家标准和指导性技术文件没有名称输入框，称谓保持固定。行业名称、地方名称仍作为兼容字段随对应名称同步保存，不再单独显示为输入项；发布单位不参与称谓推断。中文名称去除首尾空白后不能为空；编号与日期由用户填写。单位信息更新不覆盖人工修改过的前言。

## 保存与兼容规则

- 表单草稿独立于已保存数据；切换编辑器页签保留草稿。保存失败保留草稿，重置恢复已保存值；离开页面或关闭/刷新时对未保存设置提供保护。
- 设置保存一次提交 `title`、`meta`、`stage` 和同步封面的当前正文；失败前不改动编辑器封面，成功后只通过 `addToHistory: false` 事务更新封面属性，保留正文、格式、节点标记和编辑历史。
- 正文自动保存、设置保存和 XML 导入互斥。保存请求期间发生的新正文编辑继续标记为待保存，并随后排队持久化。
- 数据库明确保存的值（包括空字符串）优先；缺省字段从有效旧封面/根属性回填。可选字段清空明确写入空字符串，数据库扩展元数据保留。未知旧类型和阶段显示原值。封面称谓覆盖值为空时恢复类型默认值；国家标准和指导性技术文件始终使用固定称谓。
- 正文保存与 XML/JSON/HTML/DOCX 导出使用已保存的元数据校准封面，防止旧封面或正文撤销恢复过期信息。未保存设置需先保存或重置后再导出/导入。
