# WP4-fix：PDF 版式订正（对照 GB/T 1.1-2020 原件）

> **背景**：WP4 产出的 print 版式经主导人对照 GB/T 1.1-2020 原件（`rules/` 内 PDF，
> 附录 E/F、第 10 章）逐条核定，发现多处不符。本工作包是 WP4 的修订补丁。
> **WP5 的两遍构建与目次页码逻辑无需改动**（已实测页码与页脚 12/12 一致）；本包只改
> 渲染器与打印样式，外加一个横排 fixture 与一次重渲染核对。
>
> **规格来源**：`docs/dev-plan-phase-5.5.md` 的「GB/T 1.1-2020 版式规范（定稿）」表
> （已于 2026-06-15 按原件订正）。**实施时一律以该表 + 本清单为准；有疑义查原 PDF 图像**
> （方正书版字体，文本提取为乱码，必须以图像方式阅读；物理页 = 印刷页 + 7）。
>
> 涉及文件：`packages/shared/src/renderers/printCss.ts`、
> `packages/shared/src/renderers/html.ts`，及其测试与 fixture。

## 总则：print 变体专属的版式修正

多处英文译名仅应出现在「封面」（本系统 print 变体不渲染封面）。因此**正文首页文件名称、
图题/表题在 print 变体中一律不输出英文**。统一做法：在 `html.ts` 用 `ctx.variant === 'screen'`
门控这些英文行（screen 预览保留，print 省略），不要直接删字段（IR 仍承载双语数据）。

### F4　目次编排：收窄页码预留宽 + 缩进减半（你的 #3；codex #28 评审已采纳）
- **依据**：10.3.2 + 图 E.8：标题与页码间由"……"连接、**页码右对齐紧贴版心右缘、不加括号、点线直抵页码**；
  第一层次条空 1 个汉字、第二层次条空 2 个汉字。
- **文件**：`printCss.ts` `.ses-toc-page`（约 174 行）、`.ses-toc-l2/.ses-toc-l3`（约 171-172 行）。

- **codex #28 评审处置（采纳）**：codex 指出**不可删除** `.ses-toc-page` 的固定预留宽度——第一遍是占位

- **改为**：`.ses-toc-page { min-width: 2em; text-align: right; white-space: nowrap; }`；`l2=1em / l3=2em`。
  （占位与注入数字均右对齐于此 2em 框内、整框宽度恒定 → 两遍行宽一致、分页不漂移。）
- **验收**：目次每行点线延伸到页码框前、间隙明显缩小；一/二级条缩进为 1/2 字；
  **且改后必跑 F12 复核「两遍页数一致 + 目次注入页码与页脚 100% 一致」**（F4 回归重点）。

## 电子出版交付订正（PDF 级，对照 full-pass2/landscape 产物）

对照真实管线产出的 PDF，又发现一批与 GB/T 1.1 / 电子出版目标不一致处，于本批一并订正：

- **D1 不插正文前空白页**：电子出版只要求正文页码从阿拉伯 1 起编，不要求正文落在物理单数页。
  `printCss.ts` `.ses-body-content` 由 `break-before: right` 改为 `break-before: page`（普通另起页）。
  原「正文须从单数页起排/必要时插空白页」表述随之作废。验收：full-pass2 无正文前空白页，
  页码 I/II/III/1/2… 连续正确。
- **D2 目次内容去黑体加粗**：删除 `.ses-toc-l1 > .ses-toc-text` 的黑体加粗——表 F.1 #15 目次内容为
  五号宋体；仅「目　次」标题为三号黑体。
- **D3 前置标题全角字间隔**：`html.ts` 输出 `目　次`/`前　言`/`引　言`（两字间全角空格，图 E.8/E.9），
  非连排；16pt 为字号而非字距，不用 `letter-spacing` 硬拉。
- **D4 终结线跟随末要素页上下文**：末要素为横排表/图时，`ses-end-mark` 包入 `.ses-landscape`，
  避免回到竖排 body 页另起空白终结线页（landscape.pdf 回归）。
- **D5 有效图片**：`fullFixture` 图片改用有效小 PNG data URI（`FIG_PNG_BLUE/GREEN`），PDF 不再破图。
- **D6 最终 PDF 去哨兵**：服务端两遍管线在注入目次页码后、第二遍构建前调用 `stripBodyAnchor`
  剥离 `SESBODYSTARTANCHOR`，最终 PDF 文本层不含内部定位文本（搜索/复制/无障碍洁净）。
- **D7 公式渲染**：公式主体由服务端管线 `katex-prerender` 预渲染为静态 HTML（渲染器仍只出占位，
  WP0 结论 6）；核对产物须经服务端管线（含 KaTeX 预渲染）生成，直连 vivliostyle 的简易脚本不渲染公式。
- **D8 landscape 目次注入**：两遍构建对任意 print HTML（含横排文档）通用；核对脚本须同样对 landscape
  文档走注入流程，目次页码方非空且与页脚一致。
