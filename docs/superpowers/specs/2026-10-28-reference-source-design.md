# 文内引用与来源插入

## 目标

修复无法选择本文件引用目标、点击引用打开新网页的问题；增加术语、正文、图、表的来源插入入口。保护既有文稿，变更支持撤销。

## 方案

引用：工具栏增加“引用”，按类型和关键字选择本文件已有编号对象，以稳定 ID 保存引用；点击时在编辑器内定位，失效引用明确提示。关闭通用链接对内部引用的接管，保留外部链接行为。

来源有两条可行路径：

1. **推荐：复用现有文稿结构。** 术语写入既有 `termSource`；正文、图、表使用紧接对象后的正文段落，内容为 `[来源：用户输入]`。入口识别并编辑已有来源，支持删除。无需扩展 JSON/IR/XML 模型，现有导出可保留文字；来源与图表的位置关系由相邻段落表达。
2. 新建通用来源节点并绑定对象 ID。可以跟随对象移动，但需要扩展 PM、IR、JSON、HTML、DOCX、两种 XML 及导入边界，属于更大的格式改动。

本次建议选择方案 1。正文来源附在当前段落后；图表来源附在整个图表后，禁止写入表格单元格或图题。术语来源附在定义后，保留已有注、示例、子术语。填入内容原样保存，不核验来源真实性，不自动补全标准号或条号。

## 验收

引用选择不改变原文其他部分；点击只定位当前编辑器，旧 `refId` 和新 `targetId` 均支持；目标删除时提示。来源在四种位置可新增、编辑、删除，取消不改变文稿；保存重载、JSON/HTML/DOCX 导出及适用 XML 路径保留来源。
